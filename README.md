
# Real-Time Multimedia Image Processing System on Embedded Hardware

Real-time leaf disease detection system using CNN deployed on Raspberry Pi.

## Disease Classes
- Bacterial Spot
- Early Blight
- Late Blight
- Leaf Mold
- Healthy

## Tech Stack
- Python, TensorFlow, OpenCV
- Flask (Web Interface)
- Raspberry Pi + GPIO
- ThingSpeak IoT

## How to Run
1. Train model: python Training.py
2. Web app: python app.py
3. Camera prediction: python Prediction_cam1.py
